# Hero Images

This folder contains images for the Daily Moment section on the homepage.

## How to add images

1. Place your images (JPG, JPEG, PNG, GIF, or WebP) in this directory
2. The homepage will automatically detect and display them
3. One image is randomly selected each day (deterministic based on date)

## Example filenames

- inspiration-1.jpg
- nature-scene.png
- workspace.jpg
- sunset.webp

The system will gracefully handle an empty folder by showing only the daily quote.
